# ❄️ SnowHush | Masaüstü Kar Efekti

Bilgisayarınızın ekranına yılbaşı havası katmaya ne dersiniz? 🎄✨

SnowHush, masaüstünüzde kar yağışı ve farklı atmosfer efektleri oluşturabilen ücretsiz, açık kaynaklı bir uygulamadır.

## 💻 İndirme Bağlantıları

🍎 **MacBook / macOS 14 ve üzeri**

[Mac için indir](https://github.com/mbezruchko/Snowhush/releases/latest)

🪟 **Windows 10 / 11**

[Windows için indir](https://github.com/mbezruchko/Snowhush/releases/latest)

🐧 **Linux**

[Linux için indir](https://github.com/mbezruchko/Snowhush/releases/latest)

## 📥 Nasıl indirilir?

1. İşletim sisteminize uygun bağlantıya tıklayın.
2. GitHub sayfasındaki Assets bölümünü açın.
3. macOS için .dmg, Windows için .exe dosyasını seçin. Linux için dağıtımınıza uygun paketi indirin.
4. Uygulamayı kurun ve efektleri keşfedin! ❄️
